# Nullkey Hook

Nullkey 产品演示视频的 0–23 秒开场片段。画面全部由 HTML Canvas 逐帧绘制，不使用图片素材。

## 时间线

- `0:00–0:06`：反常识钩子——Agent 能使用 API key，但看不到它。
- `0:06–0:14`：真实凭证扩散到环境变量、配置和会话记录。
- `0:14–0:23`：会话材料进入分享、问题排查和备份流程，形成长期凭证风险。

## 使用

```bash
npm install
npm run dev
npm run still
npm run render
```

输出：

- `out/nullkey-hook.png`
- `out/nullkey-hook.mp4`
