# 日常操作路径优化

本轮以“保留任务上下文、快捷回到正在处理的对象”为准则，不新增后端接口。

| 日常操作 | 原问题 | 当前行为 |
|---|---|---|
| 项目 A 审查 diff → 项目 B → A | 自动回终端，阅读位置丢失 | 各工作区记住页签、当前运行、文件样例与滚动位置 |
| 当前任务 → 凭证/MCP/state/活动 → 任务 | 需要重新找到项目和运行 | 全局页显示来源项目/运行，“返回原任务”回原页签 |
| 文件/历史 → 当前运行 | 需要识别并再次选择运行 | 显示当前运行摘要，“返回此运行终端”不创建新沙箱 |
| 运行详情 → state → 原运行 | 查看引用后没有明确返回 | state 深链接聚焦对应记录，全局返回入口保留 |
| state 被占用 | 先点危险操作才知道不能清理 | 显示“查看占用运行”，占用期间不呈现可执行清理按钮 |
| 启动/停止进行中 | 顶部仍写“打开终端” | 主按钮按状态显示“查看启动进度/查看停止进度” |
| 管理连接 | 凭证、MCP 页面重复卡片和动作 | 每种连接一张完整卡片，授权与工具连接的状态分开 |
| 正常终端工作 | 常驻异常模拟选择器干扰 | 评审工具默认折叠，按需展开 |
| 搜索无结果 | 只剩空白 | 显示没有匹配的工作区 |

保留范围是当前原型标签页的内存，刷新仍重置；不承诺服务器端 scrollback。回到项目不会自动启动或停止，只有“打开终端/重新连接”才尝试 attach。已移除项目不提供失效返回入口。

浏览器已验证：diff 跨项目保留、全局凭证页返回同一 diff、文件返回同一运行、运行详情进入 state 后有原任务返回入口。真实终端重绘、操作系统快捷键和辅助功能完整验收仍需联调。
